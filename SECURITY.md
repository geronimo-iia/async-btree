# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No        |

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Report privately via [GitHub Security Advisories](https://github.com/geronimo-iia/async-btree/security/advisories/new) or email [jguibert@gmail.com](mailto:jguibert@gmail.com).

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected versions
- Potential impact

Expect an acknowledgement within 72 hours. A fix or mitigation will be released as a patch version once the issue is confirmed.
